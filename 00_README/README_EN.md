# ITER exploratory research dossier - Nora Niffoi

Status: public prepublication dossier, v0.1.0.

This repository contains a validated public copy of an exploratory autodidact research dossier about scientific computing, complex systems, energy, space-time, and information. It is shared to request methodological or educational guidance.

## Scientific warning

This repository does not claim any demonstrated discovery. Originality remains to be checked through bibliographic review and external scientific assessment. Physical or conceptual hypotheses are presented as hypotheses, exploratory frameworks, intuitions, or items requiring verification.

## Main axes

- FractalOS / AIONE: documentary prototype for traceability and knowledge organization.
- TimeWarp: conceptual model for temporal transitions and state changes.
- Batracien and HULK: working names for classifying configuration changes.
- Cold distortion spatial engine: hypothesis to formalize, with no propulsion claim.
- Niffoi model: exploratory framework for information, energy, and redundancy.
- Fractal and dynamical systems: multi-scale representations and transitions.
- Numerical simulations: tracks to make reproducible.
- AI-assisted autodidact research: method for structuring, critique, and documentation.
